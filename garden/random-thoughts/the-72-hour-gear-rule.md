# The 72-Hour Gear Rule

Before ordering new drone components, woodworking tooling, or camera equipment:

1. Add the item to cart.
2. Wait 72 hours.
3. If I haven't worked on the corresponding project in the last 7 days, delete the cart.

Helps prevent hoarding project materials before actually finishing existing work.
